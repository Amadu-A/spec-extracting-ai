# Шаблон Excel

`specification_v1.xlsx` подготовлен из предоставленного `examples/шаблон.xlsx`.
Исходник уже имеет формат XLSX: конвертация XLS не нужна. Сохранены лист `Лист_1`,
18 заголовков A:R, ширина столбцов, высота строк, оформление и 46 строк-образцов.
Все товарные значения удалены; в G сохранена только фиксированная валюта `RUB`.
Этот ресурс поставляется с приложением, `examples/` для экспорта не требуется.
При экспорте его копия расширяется до 19 столбцов A:S: между O «Раздел» и прежним
P «Шифр документа» добавляется «Источник/Наименование файла». Новая колонка P
получает оформление соседней заполняемой графы и ширину 30; прежние графы P:R
перемещаются в Q:S со своими размерами и стилями. Исходный ресурс не изменяется.

| JSON | Столбец | Заголовок |
|---|---|---|
| Caption | C | Номенклатура |
| Units | D | Ед. изм. |
| Quantity | E | Кол-во |
| Brand | M | Бренд |
| Article | N | Артикул |
| file_name (метаданные результата) | P | Источник/Наименование файла |
| UserComment1 | Q | Шифр документа |
| Pages | R | Страница документа |
| Note | S | Примечание |

Зелёная заливка исходника задаётся цветом темы 9 с tint 0.7999816888943144,
а не литералом CCFFCC: сохраняется именно фактически предоставленное оформление.
При экспорте более 46 позиций копируется оформление последней строки-образца.
Меньше 46 — удаляются лишние строки. Пустой результат содержит только заголовок.
Предупреждения доступны через API; дополнительных листов нет.
Значения пишутся строками без апострофа и без исполнения Excel-формул.
Имя файла берётся из задания и повторяется во всех его строках, включая строки
переносов. Оно добавляется сервером, восемь полей позиции и промпт не расширяются.
Строка-образец считывается один раз до заполнения: расширение до 20 000 позиций
не вызывает повторного сканирования уже созданных ячеек.
